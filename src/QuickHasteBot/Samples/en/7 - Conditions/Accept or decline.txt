{# Asks before pasting whether you accept, and types an acceptance or a refusal depending on the answer. Works in any text field.
js="…" checks a JavaScript expression, here the answers of ask(). Text in it goes in ' instead of ".
Inside the acceptance is a second if: it adds the suggested date only if one was entered. That's how blocks sit inside each other, every if needs its /if.
Indentation is only layout and isn't typed. That's why the space before "Does" is a space tag.}
{{ const accept = ask('Accept? (yes/no)', 'yes').trim().toLowerCase(); const when = ask('Suggested date (empty: none)', '').trim() }}

    {if,js="when != ''"}
        {space}Does {{ when }} suit you?
    {/if}
{else}
    Thanks for the invitation, unfortunately I can't make it.
{/if}
